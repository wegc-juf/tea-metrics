# teametrics v0.18.0

Released 2026-11-03.

## Features

- Added overlap-weighted `grg_cell_area` metadata to CTP and decadal AGR outputs, preserving the area through decadal processing while excluding it from amplification-factor products.
- Added an ERA5 Tx40 2.0° configuration for TEA calculation testing.

## Fixes

- Optimized weighted 5th and 95th percentile calculations using cumulative-weight lookup and reduced temporary array allocation.
- Batched materialization of Dask-backed data and weights to avoid scheduling separate computations for each timestep.
- Added per-dataset percentile timing and variable-count log messages.

## Behavior and migration

- Existing CTP caches without `grg_cell_area` can still be used, but must be recalculated to propagate cell-area metadata into newly generated decadal outputs.

## Validation

- The complete automated test suite passes on Python 3.14 (295 tests) with Poetry.
- The source distribution and wheel build successfully with Poetry 2.5.1.
