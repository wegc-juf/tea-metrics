# teametrics v0.16.0

Released 2026-10-29.

## Features

- Added configurable parallel processing for independent AGR GRG tiles through `grg_tile_workers`, with worker counts bounded by available CPUs and memory.
- Separated full-grid GRG decadal/amplification outputs from aggregate AGR outputs.
- Added ERA5 configurations for multiple GRG grid spacings and cell sizes, and support for aligning subregion static grids to a wider CTP reference grid.
- Added support for `longitude`/`latitude` coordinate aliases in geographic AGR calculations.

## Fixes

- Recomputed per-tile daily extensive fields from overlap-weighted area and population values before calculating GRG indicators.
- Applied fractional region coverage once to AGR area weights, keeping geometric GRG tile areas independent from region masks.
- Preserved separate pre-altitude and altitude-filtered masks so full and domain AGR areas use the appropriate coverage.
- Improved daily-cache reuse and loading for AGR tile calculations.

## Behavior and migration

- Altitude-filtered AGR mask files must contain `mask_full`. Regenerate older source masks before running AGR calculations; legacy GRG static caches without the full-coverage mask are regenerated when possible.
- Full-grid decadal and amplification outputs now use `GRG_...` paths, separate from aggregate outputs under `AGR_...`. Recalculate decadal products to populate the distinct output paths.
- `grg_tile_workers` defaults to `1`. Parallel tile processing is available on POSIX systems when a reusable serialized daily cache is present; otherwise calculations fall back to serial processing.

## Validation

- The complete automated test suite passes on Python 3.14 (287 tests).
- The source distribution and wheel build successfully with Poetry 2.5.1.
