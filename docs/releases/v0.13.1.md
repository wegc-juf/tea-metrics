# teametrics v0.13.1

Released 2026-09-15.

## Bug Fixes

- Fixed aggregated GeoRegion calculations so that each sub-cell recalculates its own regional daily variables instead
  of inheriting cached `*_GR` aggregates from the parent domain. This corrects `DTEMA_GR` and `DTEMP_GR`, and prevents
  the same issue for future aggregate variables.
- Passed the sliced population grid to GeoRegion sub-cells, allowing population-weighted regional variables to be
  recalculated correctly.

## Validation

- Added regression coverage for area- and population-weighted aggregate calculations in GeoRegion sub-cells.
- The complete automated test suite passes on Python 3.14.
