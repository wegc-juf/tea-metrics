# teametrics v0.17.0

Released 2026-10-29.

## Features

- Added regional SPARTACUS Tx30 configurations for Austria and its federal states, with configurable GRG tile processing.
- Added validation that region mask generation found at least one matching shape feature.

## Fixes

- Anchored projected GRG tile generation to the original source-grid lattice so crop offsets no longer shift tile coordinates between CTP and AGR phases.
- Rejected projected GRG spacing values that are not integer multiples of the source-pixel spacing.
- Regenerated shifted projected GRG static caches and aligned valid static subsets to CTP coordinates by exact tile coordinates.

## Behavior and migration

- Existing projected CTP/static results created on a crop-relative lattice may need regeneration. If a cached CTP grid does not match the source-grid-aligned lattice, recalculate daily/CTP results before decadal/AGR calculations.
- Projected `x`/`y` grids require `grg_grid_spacing` to be an integer multiple of the source-pixel spacing.

## Validation

- The complete automated test suite passes on Python 3.14 (292 tests) with Poetry.
- The source distribution and wheel build successfully with Poetry 2.5.1.
