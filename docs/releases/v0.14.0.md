# teametrics v0.14.0

Released 2026-09-24.

## Features

- Added annual population-grid support with calendar-year selection, validation, provenance, and cache protection.
- Added population exposure and population-weighted exceedance indicators at CTP, decadal, and amplification levels.
- Added gridded population basic metrics and equation-aligned compound metrics, including `EP_avg`, `pEM_avg`, `pES_avg`, and `pTEX`.
- Added decadal population-grid means for annual population data and preserved population metadata through CTP and decadal outputs.
- Added gridded `EA_avg`, `ES_avg`, and `TEX` calculations to align the ordinary gridded chain with the population-dependent chain.
- Added Tx25 and Tx30 ARDECO heatwave-analysis configurations and Tx99p configuration support.

## Fixes

- Counted events spanning CTP boundaries in every affected CTP.
- Preserved the gridded `pTEX_GR` identity after NetCDF rounding.
- Prevented metadata grids from being included in decadal spread estimators.
- Ensured multiple CTP chunks with annual population grids combine by aligned time coordinates.

## Validation

- The complete automated test suite passes on Python 3.14.
