# teametrics v0.20.0

Released 2026-11-06.

## Features

- Added automatic AGR mask generation and `--only-missing` / `--overwrite` options for region mask creation.
- Added configurable major and minor Austrian boundary overlays to the overview and Figure 5 plotting scripts, including custom shapefile paths and a `--no-borders` option.
- Added `agr_shpfile` to support a separate shapefile for AGR regions outside the `EUR`, `AFR`, and `GLO` land-sea-mask workflow.
- Restricted polygon intersection calculations to candidate grid cells and added optional parallel intersection processing.

## Fixes

- Infer subregion selection from `CNTR_ID` or `LAND_NAME` shapefile attributes and raise a clear error when the configured region is not found.
- Make shapefile-based region-mask creation work without requiring the legacy `subreg` flag.
- Ask for overwrite confirmation before starting mask calculations, avoiding unnecessary work when an existing mask is kept.

## Behavior and migration

- `subreg` is now a legacy option. If a shapefile contains `CNTR_ID` or `LAND_NAME`, the matching feature is selected automatically; a missing match is an error.
- Existing mask files are kept by default after confirmation. Use `--only-missing` to skip them or `--overwrite` to replace them without prompting.
- `agr_shpfile` applies to shapefile-based AGR mask creation; `EUR`, `AFR`, and `GLO` continue to use the intentional land-sea-mask workflow.

## Validation

- The complete automated test suite passes (299 tests).
- The source distribution and wheel build successfully with Poetry.
