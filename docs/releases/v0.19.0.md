# teametrics v0.19.0

Released 2026-11-04.

## Features

- Added `a_agr_full`, `a_agr_elig`, and `a_agr_domain` scalar area variables to decadal AGR NetCDF outputs.
- Added the `recalc_grg_static` configuration option to force regeneration of GRG static masks and area grids.

## Fixes

- Generate AGR `mask_full` from the AGR region's pre-altitude mask when the AGR differs from the calculation region.
- Regenerate legacy GRG static caches that lack matching source-region metadata, and honor `recalc_grg_static` for both same-region and cross-region AGR calculations.

## Behavior and migration

- Existing GRG static caches without source-region metadata are regenerated automatically and rewritten with region metadata.
- Existing decadal AGR NetCDF files do not contain the three new area variables; rerun the decadal AGR calculation to add them.
- Set `recalc_grg_static: true` to force static-grid regeneration when needed. It defaults to `false`.

## Validation

- The complete automated test suite passes on Python 3.14.6 (298 tests) with Poetry 2.5.1.
- The source distribution and wheel build successfully with Poetry 2.5.1.
