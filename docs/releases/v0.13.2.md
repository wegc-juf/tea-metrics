# teametrics v0.13.2

Released 2026-09-16.

## Bug Fixes

- Fixed `update_min_area()` so cached GR compound variables are recalculated after changing the minimum area.
- Invalidated stale hourly GR aggregates and CTP/decadal caches affected by a minimum-area change.
- Added regression coverage for GR recalculation and downstream cache invalidation.

After changing `min_area`, rerun `calc_hourly_indicators()` with the original hourly data if hourly indicators are
needed again.

## Validation

- The complete automated test suite passes on Python 3.14.
