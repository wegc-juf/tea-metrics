# teametrics v0.15.0

Released 2026-10-22.

## Features

- Added fractional source-pixel overlap support for GRG cells, including cell sizes smaller than GRG spacing.
- Added source-grid-aligned GRG centers and coordinate-aligned static masks/areas for geographic grids.
- Added a 2° minimum crop buffer per side for lat/lon AGR calculations; projected grids retain half-cell-size padding.
- Added population downscaling to an optional destination grid, including mask-based grid templates and projected CRS validation.
- Improved SPARTACUS regridding with dynamic CRS detection and nearest-neighbor fallback, and added validation for monthly RR aggregation inputs.
- Added Graz and SEA Tx25 configurations and support for custom configurations and dynamic year ranges in plotting workflows.

## Behavior and migration

- Use `grg_cell_size` as the canonical AGR cell-size option. `agr_cell_size` remains accepted with a deprecation warning.
- `grg_grid_spacing` is the canonical GRG spacing option. `agr_grid_spacing` remains accepted with a deprecation warning.
- GRG and AGR CTP, decadal, amplification-factor, and static-grid filenames now include both grid spacing and cell size. Existing untagged GRG/AGR result and static-grid files are ignored; regenerate them for the requested cell size.
- Cached AGR daily-basis data is reused only when its coordinate coverage contains the crop required by the current configuration; otherwise daily data is recalculated.
- The population downscaling CLI uses `--destination-grid` to specify a complete destination grid, replacing `--destination-crs`.

## Fixes

- Corrected sub-GR selection for fractional pixel overlap and area-weighted land fractions, and aligned land masks and auxiliary grids by coordinates.
- Rebuilt invalid all-NaN GRG static caches and aligned reusable static grids to CTP reference coordinates.
- Added explicit validation and logging for SPARTACUS monthly precipitation aggregation and improved regridding fallback behavior.

## Validation

- The complete automated test suite passes on Python 3.14 (268 tests).
- Updated the xarray and netCDF4 dependency lock to xarray 2026.9.0 and netCDF4 1.7.5.
